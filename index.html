GitHub Pages Setup Note:
To build and serve the live Next.js demo directly from GitHub Pages:
  1. Go to Repository Settings → Pages.
  2. Under Build and deployment → Source, select GitHub Actions (recommended) or select branch gh-pages.
  3. The automated workflow will build frontend/ and publish the app directly.
